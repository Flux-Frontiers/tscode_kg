# Release Notes — v0.1.0

> Unreleased

Initial release of TypeScriptKG: a knowledge graph for TypeScript/JavaScript
codebases built on the KGModule SDK (`kgmodule-utils`), with tree-sitter AST
extraction, a SQLite graph store, a sqlite-vec semantic index, hybrid
semantic + structural query, snippet packing, thorough architectural analysis
(CodeRank, SIR centrality, JSDoc coverage), temporal metric snapshots, a
pre-commit snapshot hook, and an MCP server exposing the full toolkit to AI
agents.

See `CHANGELOG.md` for the complete list of changes.
